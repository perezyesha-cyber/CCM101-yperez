# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic concepts and practices of working in a cloud-based Linux environment. The activity uses KillerCoda to provide a Linux playground and GitHub to create a Cloud Computing portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the KillerCoda Ubuntu 24.04 environment.
- Created and logged in to a Linux user account.
- Gathered system information.
- Created files and directories.
- Created a GitHub repository for the Cloud Computing portfolio.
