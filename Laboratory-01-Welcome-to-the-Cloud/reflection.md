# Reflection

## What I Learned

In this laboratory activity, I learned how to access and work in a cloud-based Linux environment using KillerCoda. I practiced using basic Linux commands to navigate the system, identify system information, and organize files and directories.

I also learned how to create and manage a GitHub repository and use Markdown to document my technical work.

## Challenges Encountered

One challenge I encountered was becoming familiar with the Linux terminal and remembering the commands needed to gather system information and manage files. I overcame this by carefully following the laboratory instructions and checking the results of each command.

## Skills Gained

Through this activity, I developed basic skills in Linux command-line operations, file and directory management, system information gathering, Markdown documentation, and GitHub repository management.

## Conclusion

This laboratory activity gave me a practical introduction to cloud computing environments and Linux. It also helped me understand the importance of proper documentation and version-controlled portfolios for organizing technical work.
