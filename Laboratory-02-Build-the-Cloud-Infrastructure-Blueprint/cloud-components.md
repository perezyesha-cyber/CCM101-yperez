# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose

Compute resources provide the processing power needed to run applications, services, and workloads in a cloud environment. They include resources such as CPU and memory.

### Importance in Cloud Computing

Compute resources are important because cloud applications need processing power to execute tasks. Cloud platforms allow organizations to provision and scale compute resources according to their workload requirements.

### Relation to the KillerCoda Linux Environment

The KillerCoda Linux server provides compute resources through its CPU and memory. The investigated environment has an Intel Xeon E312xx CPU with 1 CPU core and 1.9 GiB of RAM. These resources allow the Linux operating system and commands to run in the cloud environment.

---

## 2. Storage Resources

### Purpose

Storage resources provide space for storing operating system files, applications, data, and other information.

### Importance in Cloud Computing

Storage is important because cloud applications need reliable space to store and access data. Cloud storage allows organizations to keep data available for their applications and services.

### Relation to the KillerCoda Linux Environment

The KillerCoda Linux environment provides storage through its disk and mounted file systems. The server has a 19 GB root filesystem, with mounted file systems such as `/`, `/boot`, and `/boot/efi`.

---

## 3. Networking Resources

### Purpose

Networking resources allow computers, servers, applications, and users to communicate with each other.

### Importance in Cloud Computing

Networking is important because cloud resources need to communicate with users and other services. Network connectivity allows users to access cloud applications and allows different infrastructure components to exchange data.

### Relation to the KillerCoda Linux Environment

The KillerCoda Linux server has a hostname of `ubuntu` and an IP address of `172.30.1.2`. The IP address allows the server to be identified and accessed within its network environment.

---

## 4. Operating System

### Purpose

An operating system manages the computer's hardware and provides an environment for applications and users to operate.

### Importance in Cloud Computing

The operating system is important because cloud servers need software that manages compute, storage, networking, and applications. It provides the foundation on which cloud workloads and services can run.

### Relation to the KillerCoda Linux Environment

The KillerCoda environment is running Ubuntu 24.04.4 LTS with Linux kernel version 6.8.0-13-generic. The operating system manages the available CPU, memory, storage, and networking resources of the cloud server.
