# Mission Reflection

This laboratory activity helped me understand the basic components of cloud infrastructure and how they work together. Among the different components, I think compute resources are the most important because they provide the processing power needed to run applications and services. Without compute resources, other cloud components would not be able to perform their tasks properly.

Linux supports cloud computing because it provides a reliable and flexible operating system for managing cloud servers. Through the KillerCoda Linux environment, I was able to use terminal commands to check the operating system, CPU, RAM, storage, networking information, and other system resources. This helped me understand how cloud servers can be inspected and managed using Linux commands.

Technical documentation is important before deploying infrastructure because it helps engineers understand the planned system and its components. It also provides a clear record of the configuration, decisions, and resources that will be used. Good documentation can help prevent mistakes and make troubleshooting easier.

During this laboratory activity, I learned how to investigate a Linux server, identify cloud infrastructure components, compare AWS, Microsoft Azure, and Google Cloud Platform, create a simple cloud infrastructure diagram, and use Markdown for technical documentation. I also improved my understanding of basic Linux commands and GitHub repository management.

My GitHub portfolio improved because I added a complete laboratory folder with organized documentation, reports, cloud provider comparisons, reflection, and screenshots. This makes my portfolio more organized and shows my progress in learning cloud computing. Overall, this mission helped me develop both technical and documentation skills that are useful for future cloud computing activities.
