# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, networking, databases, security, and other IT needs. Organizations can use AWS to build, deploy, and manage applications without having to maintain all of their physical infrastructure.

## 2. Global Infrastructure

AWS operates a global cloud infrastructure made up of Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. This infrastructure helps organizations build applications with high availability and reliability.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources, monitor services, and manage their cloud environment through the console.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving files and other types of data.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create and manage a logically isolated network in AWS.

### AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources and helps manage users, roles, and permissions.

## 5. Three Advantages

1. **Scalability** – AWS resources can be increased or decreased based on application requirements.
2. **Global Availability** – AWS provides infrastructure in different geographic locations around the world.
3. **Wide Range of Services** – AWS offers many cloud services for different computing and business requirements.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing large amounts of data, running databases, developing software, performing data analytics, and supporting scalable business systems.
