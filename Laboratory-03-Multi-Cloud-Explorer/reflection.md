# Mission Reflection

This laboratory activity helped me learn more about AWS, Microsoft Azure, and Google Cloud Platform. Among the three cloud platforms, Microsoft Azure impressed me the most because it has many useful services and works well with Microsoft products. I also learned that AWS, Azure, and GCP are similar because they all provide services such as computing, storage, networking, databases, and security. They can also help organizations manage their applications and resources through the cloud.

I learned that business requirements are important when choosing a cloud platform. Different businesses have different needs, budgets, and technologies, so the best cloud platform depends on what the organization needs. For example, Azure is a good choice for a university that already uses Microsoft products, while Google Cloud can be useful for a company that focuses on artificial intelligence and machine learning. This taught me that we should first understand the needs of the client before choosing a cloud provider.

By acting as a Cloud Solutions Consultant, I learned how to compare different cloud platforms and choose services that can help solve a client's problem. I also learned that there is no single cloud provider that is always the best because each platform has its own strengths and features.

After completing this mission, my GitHub Cloud Computing Portfolio became more organized because I added information about AWS, Azure, and GCP. I also added comparison tables, client recommendations, and my Linux server investigation. Overall, this activity helped me understand cloud computing better and improved my skills in using GitHub and writing Markdown files.
