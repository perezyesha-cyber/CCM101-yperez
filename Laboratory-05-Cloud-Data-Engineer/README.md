# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage using MinIO and Docker.

## Objectives

- Learn the three types of cloud storage.
- Deploy a MinIO object storage server using Docker.
- Create a storage bucket and upload a sample file.
- Document the activities using Markdown.

## Tools Used

- GitHub
- KillerCoda Playground
- Docker
- MinIO
- Web Browser

## Skills Learned

- Understanding cloud storage types
- Deploying a containerized storage server
- Creating buckets and uploading files
- Writing technical documentation using Markdown
