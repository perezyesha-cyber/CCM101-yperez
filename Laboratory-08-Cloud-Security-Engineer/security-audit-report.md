---

## 01 · 👤 PRINCIPLE OF LEAST PRIVILEGE (PoLP)

> **Security Principle:** Give users only the permissions they need.

The Principle of Least Privilege means giving users only the access and permissions they need to perform their tasks. It is important for cloud user accounts because it helps prevent unauthorized access and reduces the risk of damage if an account is compromised.

---

## 02 · 🌐 ATTACK SURFACE

> **Security Principle:** Reduce unnecessary entry points.

The attack surface refers to all the points where an attacker might try to access or attack a virtual machine. Examples include open network ports, running services, and exposed applications. Reducing unnecessary services and open ports can help make the server more secure.

---

## 03 · 🧱 DEFAULT DENY POLICY

> **Security Principle:** Block incoming traffic unless it is allowed.

A Default Deny policy means blocking incoming network traffic unless it is specifically allowed by a firewall rule. It is safer because only required connections are permitted, reducing the chance of unauthorized access. Instead of trying to block every possible attacker, the administrator allows only the traffic that the server needs.
