# Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains commands that Linux can execute automatically in order. It helps users perform tasks without typing every command one by one. The `#!/bin/bash` line, also called the shebang, tells the system to use Bash to run the script.

## 2. Variables

Variables are used to store values, such as folder paths, so they can be reused in a script. For example, `$BACKUP_DIR` stores the name or path of the backup folder. Using variables makes the script easier to read and update because we do not need to change the same path in many places.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts at a specific time. It is useful in cloud operations because tasks such as backups can run automatically without someone needing to start them manually. This helps save time and reduces the chance of forgetting important tasks.
