# Laboratory 09 – Mission Reflection

In this Cloud Computing course, I learned that automation is important, especially when managing many cloud servers. Doing tasks manually takes a lot of time and can lead to mistakes. With automation, tasks like backing up files can be done automatically. For example, in this activity, I created a Bash script and used Cron to schedule the backup every day at 2:00 AM.

However, automation also has some dangers. If there is a mistake in the script, it can cause problems, especially if it runs on many servers. It might delete important files or damage the system. That is why we need to check and test scripts before using them. We should also make sure that the script performs the correct tasks.

Writing a Bash script was different from creating a Docker Compose YAML file in Laboratory 6. Bash scripts use commands to perform tasks step by step, while Docker Compose uses YAML to configure and manage application services. Both are useful because they make cloud tasks easier, but they have different purposes.

From Laboratory 1 to Laboratory 9, I learned many things about Cloud Computing. I started by learning the basics and later explored infrastructure, Docker, storage, deployment, monitoring, security, and automation. These activities helped me understand cloud computing better because I was able to practice using different tools and commands.

Among the cloud roles, I enjoyed being a Cloud Security Engineer the most because I learned how to protect systems and control access. I realized that security is very important when managing cloud environments. Overall, this course helped me improve my technical skills and learn new things that I can use in my future IT career.
