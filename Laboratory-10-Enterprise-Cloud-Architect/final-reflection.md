# Final Reflection

Throughout the CCM101 – Cloud Computing laboratory activities, I learned about different cloud technologies and how they are used to manage servers, applications, and data. From the basic Linux commands to working with Docker, networking, security, and automation, each activity helped me understand cloud computing better.

For our final laboratory activity, we worked as a group to develop a private cloud infrastructure using Ubuntu Server, Docker, and Docker Compose. Our project included PostgreSQL, Gitea, Vaultwarden, Pi-hole, and Nginx. Through this activity, I learned how different services can work together and how important proper configuration is when building a cloud environment.

I also gained a better understanding of persistent storage, firewall security, and automation. I learned that application data needs to be protected, unnecessary network access should be restricted, and repetitive tasks can be automated using scripts and scheduled jobs. These concepts are important in maintaining a reliable and secure system.

One of the lessons I learned from this group activity was the importance of teamwork. Working on a project with different components showed me that communication and cooperation are necessary to complete a technical task. It also helped me appreciate the effort needed to configure, test, and document an infrastructure.

Overall, this course helped me improve my knowledge of cloud computing and system administration. I realized that building a cloud environment requires planning, patience, security, and continuous learning. The knowledge I gained from these laboratory activities will be useful in my future projects as an Information Technology student.
